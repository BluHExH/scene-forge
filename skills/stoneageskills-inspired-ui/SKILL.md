# Stone Age Skills Inspired UI

Design and implement an original nature-learning or traditional-skills website with a topic-rich information architecture and an editorial field-guide character. Use when building an educational site inspired by broad patterns seen on Stone Age Skills. Do not reproduce that site's exact layout, branding, wording, or assets.

## Character

- Editorial field-guide feel: calm, practical, grounded in place and season.
- Rich topic hierarchy rather than marketing fluff.
- Clear sections for skills, materials, seasons, safety, and stories.
- Avoid copying any existing site’s exact structure, copy, or visual identity.

## Information architecture

- Topics → sub-skills → practical how-to pages.
- Cross-links between related skills and materials.
- Seasonal / regional context where relevant.
- Safety and ethics notes where needed.

## Visual direction

- Natural materials palette, restrained type, strong hierarchy.
- Photography or illustration that supports understanding, not decoration only.
- Mobile-first, readable long-form content.
