# Developer Productivity

Use when helping with personal productivity, task management, learning new technologies, portfolio building, or improving developer workflow efficiency.

## Daily / weekly

- Time-box deep work.
- Capture tasks in one trusted system.
- Review and prioritize weekly.
- Limit concurrent projects.

## Learning

- Project-based over pure tutorials.
- Spaced repetition for fundamentals.
- Document what you learn (short notes).

## Portfolio & career

- Ship small public projects.
- Write clear READMEs.
- Keep a short “what I shipped” log.
