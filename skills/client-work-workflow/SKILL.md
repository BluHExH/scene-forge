# Client Work Workflow

Use for client projects, freelancing, or agency work. Triggers on requirement gathering, project estimation, quotations, proposals, client communication, progress reports, and professional delivery processes.

## Typical flow

1. **Discovery** — goals, constraints, success metrics, timeline, budget range.
2. **Scope** — written deliverables, what is out of scope, assumptions.
3. **Estimate** — break into tasks, add buffer, present options (good / better / best).
4. **Proposal / Quotation** — clear pricing, timeline, payment terms, revision policy.
5. **Kickoff** — confirm access, assets, communication channel, decision makers.
6. **Delivery cadence** — milestones, demos, feedback windows.
7. **Handoff** — docs, credentials, source, training if needed.
8. **Follow-up** — support window, next opportunities.

## Communication

- Prefer written confirmation of decisions.
- Summarize meetings in short notes.
- Flag risks early.
- Never leave the client guessing about status.
