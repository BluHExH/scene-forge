# Web Performance & SEO

Use when optimizing website speed, Core Web Vitals, SEO, or accessibility.

## Performance

- Measure first (Lighthouse, Web Vitals, network waterfall).
- Optimize LCP, CLS, INP.
- Images: correct size, modern formats, lazy load.
- Code split and lazy load non-critical JS.
- Cache and CDN where appropriate.

## SEO

- Unique titles and meta descriptions.
- Semantic HTML and heading hierarchy.
- Structured data when useful.
- Fast, mobile-friendly, crawlable.
- Sitemap and robots.txt correct.

## Accessibility

- Keyboard operable.
- Sufficient contrast.
- Alt text and labels.
- Respect reduced motion.
